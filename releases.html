Release notes

What changed in each version of CaptionVid. The newest is at the top.

Version 1.0.3 26 November 2026Latest

  • Captions now stay in time with the voice all the way through. CaptionVid reads the sound on the video’s own clock, so gaps in videos saved from the web no longer push the captions ahead. Use Projects › ⋮ › Caption again on a video captioned with an older version.
  • Drag the timeline to move through the video, whether it’s playing or paused. Play carries on from where you let go.
  • The timeline’s playhead now lines up exactly with the caption being shown.
  • The script list follows the video but stays put for a few seconds after you scroll it yourself.

Version 1.0.2 26 November 2026

  • Fixed: CaptionVid closed when you tapped Download & start or Download for the speech model. The model now downloads through Android’s own download manager, so you can see it in your notifications and it carries on if you leave the app.
  • If Android won’t let captioning keep running with the screen off, it now carries on while the app is open instead of closing.
  • If CaptionVid ever closes unexpectedly, the home screen offers the details to copy and send, so it can be fixed quickly.

Version 1.0.1 26 November 2026

  • Fixed: CaptionVid closed as soon as it started captioning a video, and then every time it was opened while that video was still waiting. Captioning now starts properly.
  • If a video ever makes captioning stop unexpectedly twice, it is set aside as failed so the app always opens. Tap it to try again.
  • CaptionVid only starts its background work when there are videos waiting.

Version 1.0.0 26 November 2026

  • First release. Word-by-word captions made on the phone in the background, with a queue, share-to-app, a watch folder and recording with a teleprompter.
  • 45 animated looks, 171 fonts, your own fonts, saved looks, brand kits and safe-zone guides.
  • Editing by word or by line, find and replace, undo and redo, silence and filler cutting, speaker colours and translation into 34 European languages.
  • Export with captions burned in up to the video's own size, switchable subtitle tracks, background noise removal, and SRT, WebVTT, ASS and plain-text files.

Checking your download

The file for version 1.0.3 is called CaptionVid.apk. It is 30.8 MB (30,776,113 bytes). Its SHA-256 checksum is:

f53d69979e0ed7cc559bc75d5205bd402c5f972c1697707bf84835624dc446d8

On Windows, run certutil -hashfile CaptionVid.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
